# Xiaohongshu

Tool-dependent workflow, not an unattended uploader. No live-account verification is claimed.

Before opening a form, reserve the destination using claim as described in [authorization](../authorization.md). A failed claim means stop.

1. Open https://creator.xiaohongshu.com/ in the host browser. Inspect the current interface and submission rules; do not assume stored selectors are current. Stop for login or challenges.
2. Verify the visible account against the approved destination. For publications verify recipient, guidelines, exclusivity and required rights declarations; obtain any missing factual information.
3. Read the prepared preview. Upload its exact media in order and enter the selected locale's title/body. Check whether current account supports this media type and length. Do not silently resize, truncate, translate or drop attachments.
4. Inspect the final form, visibility, cover, tags and any required disclosures. If content or settings differ from the approved artifact, prepare a revised package and obtain approval.
5. Submit once only after matching explicit approval or scoped authorization. Capture a stable post URL, submission identifier or confirmation evidence.
6. Record published for an actual social post, submitted for a publication receipt. If the page times out after submission, stop and inspect history; never blindly click again. Record unresolved outcomes as unknown rather than failure.

If browser tools are unavailable, leave the destination blocked and provide the prepared package for manual handoff.
